ALGORITMO

O que é? Sequência lógica de passos usada para resolver um problema.

É uma sequência lógica, finita e definida de instruções passo a passo para resolver um problema ou
realizar uma tarefa. Funcionam como "receitas" que guiam o computador, essenciais para a automoção e
criação de software. Vida real: Uma receita de bolo, o manual de montagem de um móvel,
ou o processo de trocar uma lâmpada. Computação: O algoritmo sugere em redes sociais,
o sistema que decide o que aparece no Youtube, ou um programa simples de calculadora.


Alguns exemplos de algoritmos na vida real e na computação:

Quando falamos de algoritmos, pensamos em matemática e programação.
Porém, temos exemplos de algoritmos que estão muito presentes nas nossas atividades cotidianas.
Por exemplo, conseguimos criar um bolo a partir de um algoritmo. Começamos organizando os ingredientes,
seguimos a sua receita e terminamos com o nosso bolo como resultado final.
Ao transpassar esse exemplo para o campo da programação, em que o conceito de algoritmo é amplamente utilizado, temos que:

  • Nossos ingredientes são a entrada de dados;
  • A receita representa os operadores lógicos e aritméticos;
  • O bolo é o resultado final.

Assim, o algoritmo é a base para a construção de programas e sistemas, pois ele define a lógica que o computador
deve seguir para alcançar um resultado específico. Ele é fundamental para a automação de tarefas,
a resolução de problemas complexos e a criação de soluções eficientes em diversas áreas da tecnologia.

API

O que é? Interface que permite a comunicação entre diferentes sistemas.

As APIs são um conjunto de padrões que fazem parte de uma interface.
As APIs permitem a criação de plataformas de maneira mais simples e prática para desenvolvedores.
A partir deles (APiS), é possível criar softwares, aplicativos, programas e plataformas diversas.
Por exemplo, apps desemvolvidos para celulares Android e Iphone (iOS) são criados a paritr de padrões definidos
e disponibilizados pelas APIs de cada sistema operacional.


Exemplos de APIs:

  • Google Maps
  • Twitter
  • Facebook
ARRAY

O que é? Estrutura de dados que armazena múltiplos valores em uma única variável.

Um array (ou arranjo/vetor) é uma estrutura de dados fundamental que armazena uma coleção ordenada de elementos,
geralmente do mesmo tipo, em posições contíguas na memória. Cada elemento é acessado por um índice numérico,
que frequentemente começa em zero. São ideais para agrupar múltiplos dados sob uma única variável,
facilitando o gerenciamento e a manipulação.

Exemplo de array em JavaScript:

  • var carros = ["Saab", "Volvo", "BMW"]
ASCII

O que é? Padrão que representa caracteres em formato numérico.

O ASCII é um código que foi proposto por Robert W. Bemer como uma solução para unificar a
representação de caracteres alfanuméricos em computadores. Antes de 1960, cada computador utilizava
uma regra diferente para representar estes caracteres e o código ASCII nasceu para se tornar comum
entre todas as máquinas.


Principais características:

  • Representa caracteres usando números de 0 a 127.
  • Inclui letras maiúsculas e minúsculas, dígitos, pontuação e caracteres de controle.
  • É um padrão de codificação de caracteres amplamente utilizado em sistemas de computação.
  • A letra "A" maiúscula corresponde ao número decimal 65 (binário 0100001).

BACK-END

O que é? Parte do sistema responsável pela lógica e processamento de dados.

O back-end é a parte "invisível" de uma aplicação (servidor, banco de dados e lógica) que processa informações,
gerencia dados e garante o funcionamento correto do sistema. Ele é responsável por receber as requisições do usuário,
processar essas informações e enviar as respostas adequadas. Quando acessamos um site, por exemplo, por trás de toda a
sua apresentação amigável esteticamente,
há uma comunicação das informações trocadas
entre banco de dados e navegador.


BANCO DE DADOS

O que é? Sistema organizado para armazenar e gerenciar informações.

Os bancos de dados armazenam informações que podem ser usadas para diferentes finalidades,
incluindo análise, exploração e consulta.
Auxiliando tanto em tomadas de decisões como no funcionamento de sistemas ou programas.
Os bancos de dados são fundamentais para a construção dessa arquitetura de dados.
Eles são mais do que apenas um lugar para armazenar informações. Em vez disso,
permitem que as organizações gerenciem dados de forma centralizada, reforcem a integridade dos dados e
os padrões de segurança e facilitem o acesso a dados.
Podemos compará-lo a uma biblioteca, onde os dados são os livros e o sistema de gerenciamento de banco de dados (SGBD) é o bibliotecário.
O bibliotecário é responsável por organizar, catalogar e facilitar o acesso às informações.


Os bancos de dados são usados em uma ampla variedade de aplicações, incluindo:

  • Sistemas de gerenciamento de conteúdo (CMS) para sites e blogs.
  • Plataformas de comércio eletrônico para armazenar informações de produtos e clientes.
  • Redes sociais para gerenciar perfis de usuários, postagens e interações.
  • Aplicativos de mensagens para armazenar conversas e contatos.
  • Sistemas de gerenciamento de relacionamento com clientes (CRM) para armazenar dados de clientes e interações.

Qual o papel dos bancos de dados?

O papel do banco de dados nas empresas pode ser dividido em três principais funções:

  • Armazenamento de Dados: O banco de dados serve como um repositório centralizado para armazenar grandes volumes de
    dados de forma organizada e estruturada. Ele permite que as empresas mantenham informações importantes, como dados de clientes, transações,
    inventário e muito mais.

  • Gerenciamento de Dados: Além de armazenar dados, os bancos de dados oferecem ferramentas para gerenciar e manipular
    essas informações. Isso inclui a capacidade de criar, ler, atualizar e excluir dados (CRUD), bem como a implementação de regras de integridade
    para garantir a consistência dos dados.

  • Suporte à Tomada de Decisões: Os bancos de dados permitem que as empresas acessem e analisem seus dados
    para tomar decisões informadas. Através de consultas e relatórios, as organizações podem obter insights valiosos sobre suas operações, clientes e mercado,
    o que pode levar a estratégias mais eficazes e competitivas.

    • BOOLEAN

    O que é? Tipo de dado que representa verdadeiro ou falso.

    Um booleano (ou boolean) é um tipo de dado lógico na computação que representa apenas
    dois estados possíveis: verdadeiro (true) ou falso (false).
    Nomeado em homenagem a George Boole, esse tipo é fundamental para operações condicionais,
    permitindo que algoritmos tomem decisões baseadas em lógica (AND, OR, NOT).

    Os operadores booleanos mais utilizados são:

    • AND (E): Retorna verdadeiro se ambos os operandos forem verdadeiros. Exemplo: true AND true = true; true AND false = false.

    • OR (OU): Retorna verdadeiro se pelo menos um dos operandos for verdadeiro. Exemplo: true OR false = true; false OR false = false.

    • NOT (NÃO): Inverte o valor lógico do operando. Exemplo: NOT true = false; NOT false = true.

    BUG


    O que é? Erro no código que gera comportamento inesperado.

    Bug é um jargão da informática que se refere às temidas falhas inesperadas que ocorrem ao executar algum software ou usar um hardware.
    Esses erros imprevisíveis que prejudicam o funcionamento correto de alguma tecnologia podem desencadear problemas incômodos, como travamentos e
    roubar informações sigilosas. As falhas inesperadas são uma porta de entrada para os crimes cibernéticos.
    A palavra inglesa bug significa literalmente "inseto". Não se sabe ao certo qual é a origem do termo para designar falhas em softwares e hardwares,
    mas a explicação mais aceita relata um erro que ocorreu, 9 de setembro de 1947, no computador Mark II, operado pela Marinha dos Estados Unidos.
    O operador William Burke encontrou dentro da máquina uma mariposa que estava presa entre os fios, causando uma falha no funcionamento do computador.
    Depois, ele relatou em seu diário de bordo um caso real de "inseto (bug) sendo encontrado". A partir do acontecimento,
    a definição acabou sendo adotada no vocabulário de tecnologia e informática.



    Bugs Famosos: Ninguém está imune!

    Bugs acontecem a todo momento e alguns ficam conhecidos dependendo do número de usuários atingidos ou estragos provocados.
    No final de 2018, o Facebook divulgou uma falha grave na rede social que expôs fotos não publicadas de cerca de 6,8 milhões de usuários.
    O erro atingiu pessoas que permitiram o acesso de aplicativos de terceiros à sua mídia na plataforma devido a um bug de permissão.
    Em outubro de 2018, a Microsoft teve de suspender a atualização Windows 10 October 2018 devido a um bug que provocava a remoção acidental de arquivos do PC.
    O problema foi resolvido em dezembro, quando a empresa atualizou o software e voltou a disponibilizá-lo para download.

    CSS

    O que é? Linguagem usada para estilizar páginas HTML.

    CSS (Cascading Style Sheets), ou Folhas de Estilo em Cascata, é uma linguagem usada para definir o estilo visual de páginas web.
    Ele permite personalizar cores, fontes, tamanhos, espaçamentos, posições e diversos outros aspectos de um site.
    Enquanto o HTML é responsável por estruturar o conteúdo, o CSS se encarrega por torná-lo visualmente atraente e acessível.
    Imagine o HTML como os blocos de construção de uma casa (paredes, portas e janelas). O CSS, por sua vez, seria a pintura, a decoração e os acabamentos
    que deixam tudo com a sua cara. Ficou mais claro?
    É válido ressaltar que essa separação entre estrutura e estilo é bastante relevante, pois ajuda a manter o código mais organizado, reutilizável e eficiente,
    além de facilitar a manutenção e melhorar a performance das páginas.
    Ao aplicar o CSS corretamente, é possível garantir uma identidade visual consistente em todo o site, aspecto essencial para qualquer negócio que deseja
    se destacar na internet.



    Princípios do CSS:


    • Seletores: Permitem escolher quais elementos HTML serão estilizados. Exemplo: p { color: blue; } seleciona todas as tags

      e as torna azuis.


    • Propriedades e Valores: Definem o estilo a ser aplicado. Exemplo: font-size: 16px; define o tamanho da fonte como 16 pixels.

    • Cascata e Especificidade: Regras que determinam qual estilo é aplicado quando há conflitos entre diferentes regras CSS.
      Exemplo: Se um elemento tem uma classe e um ID, o ID tem maior especificidade e prevalece sobre a classe.

    • Box Model: Conceito que descreve a estrutura de um elemento HTML, incluindo margens, bordas, preenchimento e conteúdo.
      Exemplo: margin: 10px; adiciona uma margem de 10 pixels ao redor do elemento.

    • Responsividade: Princípio de design que garante que as páginas se adaptem a diferentes tamanhos de tela e dispositivos.
      Exemplo: @media (max-width: 600px) { ... } aplica estilos específicos para telas com largura máxima de 600 pixels.
    CLASSE

    O que é?Atributo usado para aplicar estilos a múltiplos elementos.

    Uma classe CSS é um atributo usado em HTML para selecionar e estilizar elementos específicos.
    Ela permite aplicar simultaneamente o mesmo conjunto de regras de estilo — como cor, tamanho da fonte ou espaçamento — a vários elementos ao mesmo tempo,
    em vez de codificar cada um individualmente.


    Como funciona?
    Uma classe de Folhas de Estilo em Cascata (CSS) funciona criando um "rótulo" reutilizável que vincula sua estrutura de
    Linguagem de Marcação de Hipertexto (HTML) às suas regras de CSS.
    Ao atribuir uma classe a um elemento HTML , você está instruindo o navegador a encontrar a definição de estilo dessa classe na folha de estilo e
    aplicá-la a esse elemento específico.
    Isso cria uma poderosa separação de responsabilidades. Seu arquivo HTML lida com o conteúdo (o "quê"),
    enquanto sua folha de estilo lida com a apresentação (o "como fica").
    Por exemplo, imagine que você tenha cinco caixas de "alerta" em seu site, todas com borda vermelha e texto em negrito.
    Em vez de estilizar cada caixa individualmente, você pode criar uma única classe chamada .alert em seu CSS.
    Em seguida, basta adicionar a classe "alert" a cada uma das cinco caixas no seu HTML. Se mais tarde você decidir mudar a borda para azul,
    basta fazer a alteração uma única vez na definição da classe " .alert" , e todas as cinco caixas serão atualizadas automaticamente.


    CÓDIGO-FONTE

    O que é? Conjunto de instruções escritas pelo programador.

    Código-fonte ou source code é um conjunto de instruções escrito em linguagem de programação que define um software.
    Em outras palavras, trata-se do código estrutural de um programa de computação que pode ser interpretado ou compilado por uma máquina para o
    funcionamento da aplicação.


    Para que serve o código-fonte?

    O código-fonte serve para a execução e o funcionamento correto de uma aplicação computacional. Isso porque, além de definir como o software vai se comportar,
    o código será compilado (transformado em código de máquina) ou lido por um interpretador para que a máquina consiga rodar o programa.
    Além disso, o código-fonte tem a função de habilitar a edição das instruções: o programador com acesso ao source code pode alterar as linhas de programação
    para modificar comportamentos, corrigir erros ou vulnerabilidades, bem como otimizar sua estrutura para melhor desempenho.


    COMPILADOR

    O que é? Programa que traduz código para linguagem de máquina.

    Um compilador é um tipo de programa de computador que converte código de uma linguagem de programação (a linguagem-fonte) em outra linguagem de
    programação (a linguagem-alvo). Compiladores são usados para transformar código-fonte de alto nível em código-alvo de baixo nível
    (como linguagem assembly, código-objeto ou código de máquina), preservando a funcionalidade do programa.
    Ferramentas crítica para a programação de computadores moderna e prática, os compiladores permitem que os programadores trabalhem em código de alto
    nível legível por humanos e, em seguida, convertam o código-fonte em código de destino executável. Compiladores também ajudam desenvolvedores de
    software a criar programas executáveis eficientes com segurança, estabilidade e portabilidade aprimoradas. Isso porque os compiladores auxiliam na identificação e
    resolução de erros, criando aplicações executáveis portáteis.
    Embora todos os compiladores convertam código de alto nível em código executável de baixo nível, diferentes tipos de compiladores são usados para diferentes
    linguagens de programação e aplicações. Por exemplo, um compilador cruzado é usado para produzir código para um tipo diferente de CPU ou sistema operacional
    daquele no qual está em execução.
    Quando o compilador ideal não está disponível ou ainda não foi desenvolvido, um compilador bootstrap temporário é usado para compilar um compilador mais
    permanente, melhor otimizado para compilar qualquer linguagem de programação específica.

    DOM

    O que é? Estrutura que representa os elementos da página como objetos.

    DOM é uma sigla para o termo em inglês Document Object Model. Em português, é a definição para Modelo de Documento por Objetos.
    Ou seja: uma interface de programação utilizada pelos navegadores para representar as páginas que encontramos na rede.
    Por padrão, o DOM oferece uma representação estruturada para documentos HTML, XML e SVG.
    Além disso, ele define métodos que vão permitir acesso aos dados dispostos em um formato de árvore e altera estrutura, estilo e conteúdo presentes no documento.
    Dessa forma, podemos definir como DOM JavaScript o sistema que permite manipular e modificar elementos de um documento web.
    Ele se conecta a diversas linguagens de programação, como Python e PHP, para levar essas informações à página em questão.


    O que é Object Document?

    É a estrutura hierárquica que o DOM cria a partir de um documento HTML ou XML.
    Ele organiza todos os elementos em uma árvore de objetos, onde cada nó representa um elemento, atributo ou texto.
    Esses objetos podem ser manipulados usando linguagens como JavaScript, entregando os resultados exibidos ao acessar um site.


    Outros dados fundamentais sobre o DOM

    Quando se fala sobre DOM também é importante se atentar aos seguintes dados fundamentais:

    • O DOM é uma interface de programação que representa documentos HTML e XML como uma estrutura de árvore de objetos.

    • Ele permite que os desenvolvedores acessem e manipulem o conteúdo, a estrutura e o estilo de uma página web usando linguagens de programação como
      JavaScript.

    • O DOM é amplamente utilizado para criar páginas web dinâmicas e interativas, permitindo que os elementos sejam modificados em tempo real com
      base nas ações do usuário ou em eventos.

    DEPLOY

    O que é? Processo de publicar um site ou sistema na internet.

    Deploy (ou implantação) é o processo de pegar um software, site ou aplicação que foi desenvolvido no computador do programador e colocá-lo em um servidor,
    tornando-o acessível aos usuários finais. É a etapa de "colocar no ar", passando do ambiente de desenvolvimento para produção.
    Em termos gerais, ele é utilizado para descrever que algo foi colocado na sua posição. Na prática, também é utilizado quando um sistema foi disponibilizado para
    uso – seja no ambiente de desenvolvimento, para testes ou produção.
    Imagine que você criou um site, mas deixou ele parado na sua máquina. No momento em que você o incorporar em um servidor de hospedagem,
    esse processo será considerado um deploy.
    Outro exemplo é quando é gerada uma nova versão de um programa e o desenvolvedor quer implantá-lo em um servidor de aplicação. Ou seja, subir os arquivos
    atualizados para um servidor – que pode ser um ambiente de homologação ou de produção. Isso também significa fazer um deploy.
    Mas atenção: não confunda implantar com implementar, pois são coisas bem diferentes!
    Implantar consiste em iniciar alguma coisa, enquanto implementar é o ato de colocar essa coisa em prática. Trazendo para a nossa área, quando se inicia o
    desenvolvimento de um sistema, ele está sendo implantado. No momento em que passa a ser utilizado pelos usuários, foi implementado.



    DNS

    O que é? Sistema que traduz nomes de domínio em IP.

    O DNS (Domain Name System) é o sistema responsável por traduzir nomes de domínio legíveis por humanos (ex: google.com) em endereços
    IP numéricos (ex: 192.0.2.44) que computadores usam para se comunicar. Funciona como uma agenda telefônica da internet, permitindo localizar sites sem decorar
    IPs.

    Principais características do DNS:

    • Hierarquia: O DNS é organizado em uma estrutura hierárquica, com domínios de nível superior (TLDs) como .com, .org, .net, seguidos por subdomínios e hosts.

    • Resolução de Nomes: O processo de tradução de um nome de domínio para um endereço IP é chamado de resolução de nomes, realizada por servidores DNS.

    • Servidores DNS: Existem diferentes tipos de servidores DNS, incluindo servidores raiz, servidores de TLD e servidores autoritativos, cada um desempenhando um papel específico na resolução de nomes.

    • Cache: Para melhorar a eficiência, os servidores DNS e os clientes mantêm caches de consultas anteriores, reduzindo o tempo de resolução para domínios frequentemente acessados.

    • Segurança: O DNS é vulnerável a ataques como envenenamento de cache e ataques DDoS, e existem medidas de segurança como DNSSEC para proteger a integridade das respostas DNS.



    DEBUG

    O que é? Processo de identificar e corrigir erros.

    Debug, ou depuração, é o processo de identificar, localizar e corrigir erros (bugs), falhas de lógica ou comportamentos inesperados em softwares.
    Envolve inspecionar o código, analisar variáveis e acompanhar o fluxo de execução para garantir que o sistema funcione corretamente.
    Essencial para a qualidade, é realizado por ferramentas como debuggers e análise de logs.


    Principais etapas do processo de debug:

    • Identificação do Problema: O primeiro passo é reconhecer que há um bug ou erro no software. Isso pode ser feito por meio de testes, feedback de usuários ou monitoramento de logs.

    • Reprodução do Erro: Tentar reproduzir o erro de forma consistente é crucial para entender as condições que o causam. Isso pode envolver a execução do software em um ambiente controlado ou a criação de casos de teste específicos.

    • Isolamento do Problema: Depois de reproduzir o erro, o próximo passo é isolar a parte do código que está causando o problema. Isso pode ser feito usando técnicas como impressão de mensagens de depuração, uso de breakpoints ou análise de pilha de chamadas.

    • Correção do Erro: Uma vez que o código problemático foi identificado, o próximo passo é corrigir o erro. Isso pode envolver a modificação do código, a adição de verificações de validação ou a implementação de uma solução alternativa.

    • Teste da Correção: Após corrigir o erro, é importante testar a correção para garantir que o problema foi resolvido e que não introduziu novos bugs. Isso pode ser feito por meio de testes unitários, testes de integração ou testes de regressão.

    • Documentação: Por fim, é útil documentar o processo de depuração, incluindo a natureza do bug, a solução implementada e quaisquer lições aprendidas. Isso pode ajudar a prevenir erros semelhantes no futuro e facilitar a manutenção do software.

    ELEMENTO

    O que é? Parte de uma página HTML composta por tags.

    Um elemento HTML é a unidade básica de construção de uma página web, composto por uma tag de abertura, conteúdo e, geralmente,

    EVENTO

    O que é? Ação do usuário como clique ou digitação.

    Um evento em programação é uma ação ou ocorrência reconhecida pelo software — como um clique de mouse, pressionamento de tecla ou
    carregamento de página — que aciona uma resposta específica do código. Esse paradigma, conhecido como Programação Orientada a Eventos,
    permite que aplicações sejam interativas e assíncronas, reagindo a ações do usuário em tempo real.


    Tipos comuns de eventos:

    • Eventos de Mouse: Incluem ações como click, dblclick, mouseover, mouseout e mousemove, que ocorrem quando o usuário interage com o mouse.

    • Eventos de Teclado: Incluem keydown, keyup e keypress, que ocorrem quando o usuário pressiona ou solta uma tecla no teclado.

    • Eventos de Formulário: Incluem submit, change e input, que ocorrem durante a interação do usuário com formulários HTML.

    • Eventos de Janela: Incluem load, resize e scroll, que ocorrem em relação à janela do navegador ou ao documento.

    • Eventos Personalizados: Desenvolvedores podem criar seus próprios eventos personalizados para atender a necessidades específicas de suas aplicações.


    ESCOPO

    O que é? Região onde uma variável pode ser acessada.

    Escopo na programação define a visibilidade e o tempo de vida de variáveis, funções e objetos em partes específicas do código.
    Ele determina onde um identificador pode ser acessado, evitando conflitos de nomes e economizando memória.
    Os principais tipos são global (acessível em todo o script) e local (restrito a um bloco, função ou chave)


    Principais Tipos de Escopo:

    • Escopo Global: Variáveis e funções declaradas no escopo global estão acessíveis em qualquer parte do código. Exemplo: var globalVar = "I am global";

    • Escopo Local: Variáveis e funções declaradas dentro de uma função ou bloco têm escopo local, sendo acessíveis apenas dentro desse contexto. Exemplo: function myFunction() { var localVar = "I am local"; }

    • Escopo de Bloco: Introduzido com o ES6, permite que variáveis declaradas com let ou const sejam limitadas ao bloco em que foram definidas. Exemplo: { let blockVar = "I am block scoped"; }

    • Escopo de Função: Variáveis declaradas dentro de uma função são acessíveis apenas dentro dessa função. Exemplo: function anotherFunction() { var functionVar = "I am function scoped"; }

    FRONTEND

    O que é? Parte visual da aplicação.

    Front-end é a parte de um site ou aplicativo com a qual os usuários interagem diretamente, abrangendo elementos visuais, estrutura e interatividade.
    Utilizando tecnologias como HTML, CSS e JavaScript, os desenvolvedores transformam designs em interfaces responsivas.
    O objetivo é garantir a melhor experiência do usuário (UX) e funcionalidade.


    Diferença entre Front-end e Back-end:

    O front-end é a camada de apresentação, responsável por tudo o que o usuário vê e interage, enquanto o back-end é a camada de lógica e dados,
    lidando com a funcionalidade e armazenamento.
    O front-end se concentra na experiência do usuário, utilizando tecnologias como HTML, CSS e JavaScript para criar interfaces visuais.
    Já o back-end utiliza linguagens como Python, Java ou Node.js para processar dados, gerenciar servidores e
    garantir que as funcionalidades do site ou aplicativo funcionem corretamente.


    FUNÇÃO

    O que é? Bloco de código reutilizável.

    Função é um bloco de código que pode ser chamado e executado em diferentes partes do programa, permitindo a reutilização de lógica e facilitando a
    manutenção do código. Elas organizam o código, facilitam a manutenção e evitam a repetição, permitindo chamar o mesmo trecho várias vezes.


    Como utiliza-la?

    Para utilizar uma função, primeiro é necessário defini-la, atribuindo um nome e especificando os parâmetros (se houver). Depois, basta chamar a função pelo nome,
    passando os argumentos necessários. Exemplo em JavaScript:

    • function greet(name) { return "Hello, " + name + "!"; }

    • console.log(greet("Alice")); // Output: Hello, Alice!


    FRAMEWORK

    O que é? Estrutura que facilita o desenvolvimento.

    Um framework é uma estrutura de código pré-escrito, bibliotecas e diretrizes que fornece uma base para o desenvolvimento rápido e padronizado de software.
    Ele funciona como um "esqueleto", permitindo que desenvolvedores foquem na lógica de negócio (o que é único no projeto) em vez de recriar funcionalidades básicas.


    Principais características e vantagens:

    • Produtividade
    • Padronização
    • Reutilização de componentes
    • Manutenção facilitada


    Exemplos populares por área:

    • Web Front-end: React, Angular, Vue.js

    • Web Back-end: Express.js, Django, Ruby on Rails

    • Mobile: Flutter, React Native, Xamarin

    • Desktop: Electron, Qt, WPF

    • Data Science: TensorFlow, PyTorch, Scikit-learn


    G



    GIT

    O que é? Sistema de controle de versão.

    O Git é um sistema de controle de versão distribuído, gratuito e de código aberto, projetado para rastrear alterações em arquivos de computador,
    sendo amplamente utilizado no desenvolvimento de software para gerenciar o código-fonte. Ele registra histórico de modificações, permitindo reverter para versões
    anteriores e facilitando a colaboração entre desenvolvedores.


    Principais conceitos e características do Git:
    • Controle de Versão: Rastreia mudanças, permitindo saber quem alterou o quê, quando e por que.
    • Distribuído: Diferente de sistemas antigos, cada desenvolvedor possui uma cópia local do histórico completo do projeto, o que torna operações mais rápidas e permite trabalhar offline.
    • Snapshots (Fotografias): O Git tira uma "foto" de todos os seus arquivos a cada commit, em vez de apenas registrar diferenças, tornando o gerenciamento mais eficiente.
    • Segurança: Utiliza um algoritmo de verificação (checksum) chamado SHA-1 para garantir a integridade dos dados, tornando impossível alterar arquivos sem que o Git detecte.
    • Git vs GitHub: O Git é a ferramenta instalada na sua máquina. O GitHub, Bitbucket ou GitLab são plataformas em nuvem que hospedam esses repositórios Git, facilitando o trabalho em equipe.


    GITHUB

    O que é? Plataforma para hospedagem de código.

    O GitHub é uma plataforma baseada na nuvem que hospeda projetos de software, funcionando como um
    repositório remoto para controle de versão usando o sistema Git. Ele permite que desenvolvedores armazenem,
    gerenciem e colaborem em códigos, sendo essencial para trabalho em equipe, projetos de código aberto
    (open source) e portfólios profissionais, além de oferecer ferramentas de IA como o Copilot.

    Principais características e usos:
    • Hospedagem de Código: Armazena repositórios de projetos na nuvem.

    • Controle de Versão (Git): Permite acompanhar alterações, retornar a versões anteriores e
      gerenciar ramificações (branches) do código.

    • Colaboração: Facilita o trabalho conjunto através de Pull Requests (solicitações de alteração)
      e Issues (relato de problemas).

    • Rede Social de Desenvolvedores: Funciona como uma vitrine profissional onde programadores
      compartilham trabalhos e contribuem para projetos de terceiros.

    • Automação: Oferece ferramentas para automação de fluxo de trabalho e
      implementação de software.

    GRID

    O que é? Layout em grade no CSS.

    O "grid" (ou grade/malha) é uma estrutura de linhas guias (horizontais e verticais) usada para organizar
    elementos de maneira coesa e equilibrada. Essencial no design gráfico para layouts e desenvolvimento web (CSS),
    o termo também refere-se a redes elétricas, computação distribuída e filas de largada.



    H

    HTML

    O que é? Linguagem de marcação usada para estruturar páginas web.

    HTML (HyperText Markup Language) é a linguagem de marcação usada para criar a estrutura de uma página web
    Imagine que o HTML é o esqueleto de um site — ele define os elementos que você vê em uma página: títulos,
    parágrafos, imagens, links, botões, tabelas, etc. Com HTML, você consegue construir a "base" do site.


    HTML é composto de tags que indicam o que cada parte do conteúdo significa.
    Algumas das tags mais comuns são:

    • <h1> a <h6>: Representam títulos de diferentes níveis, de <h1> (o mais importante)
      a <h6> (o menos importante).

    • <p>: Define um parágrafo de texto.

    • <a>: Cria links (âncoras) para outras páginas ou locais na mesma página.



    HTTP

    O que é?Protocolo de comunicação da web.

    HTTP (Hypertext Transfer Protocol) é o protocolo base da World Wide Web, funcionando no
    modelo cliente-servidor para transferência de documentos hipermídia, como HTML. Ele permite que navegadores
    (clientes) solicitem recursos e servidores respondam, sendo um protocolo "stateless" (sem estado), onde cada
    requisição é independente.



    HTTPS

    O que é? Versão segura do HTTP com criptografia.

    HTTPS (Hypertext Transfer Protocol Secure) é a versão segura do HTTP, utilizando criptografia
    SSL/TLS para proteger a troca de dados entre um navegador e um servidor. Ele garante confidencialidade,
    integridade e autenticidade, protegendo informações sensíveis (senhas, cartões) contra interceptações e sendo um
    fator de ranqueamento do Google.



    I

    ID

    O que é? Identificador único de um elemento HTML.


    ID é uma sigla para o inglês identity (identidade) ou identifier (identificador), significando um código
    único (números ou letras) usado para identificar unicamente um usuário, dispositivo ou registro em sistemas
    digitais. Exemplos comuns incluem ID de usuário em apps, IDs de dispositivos móveis (IDFA/ID de anúncio) para
    rastreamento e IDs de banco de dados.


    INPUT

    O que é? Campo de entrada de dados.

    Input significa entrada, inserção ou absorção de algo.
    Em tecnologia, refere-se a dados inseridos em sistemas (via teclado, mouse, voz) para processamento
    No aprendizado de idiomas, representa absorção de conteúdo (leitura/escuta). Na gestão, engloba recursos
    inseridos (mão de obra, materiais) para gerar produtos (output).



    IP

    Endereço único de um dispositivo na rede.

    IP, ou Internet Protocol (Protocolo de Internet), é um endereço numérico exclusivo que
    identifica dispositivos (computadores, celulares, TVs) em uma rede local ou na internet.
    Ele funciona como um "CEP" ou "CPF" digital, essencial para rotear e entregar dados ao destino correto.
    Sem ele, a comunicação online seria impossível.




    J

    JAVASCRIPT

    O que é? Linguagem usada para criar interatividade em páginas web.

    JavaScript é uma linguagem de programação de alto nível, interpretada e voltada para objetos,
    essencial para tornar páginas web interativas e dinâmicas. Enquanto HTML estrutura e CSS estiliza,
    o JavaScript adiciona "inteligência", permitindo animações, validações, mapas interativos e atualização
    de conteúdos sem recarregar a página.



    JSON

    O que é? Formato leve de troca de dados.

    JSON (JavaScript Object Notation) é um formato leve de texto, independente de linguagem,
    usado para armazenar e trocar dados estruturados entre sistemas, comumente em APIs e aplicações web.
    Baseado na sintaxe de objetos JavaScript, ele organiza informações em pares de chave/valor, sendo fácil
    de ler por humanos e rápido para máquinas processarem.




    L

    LOOP

    O que é? Estrutura de repetição de código.

    Um loop (ou laço) é uma estrutura de repetição usada para executar um conjunto de instruções
    várias vezes automaticamente até que uma condição específica seja atendida. Essencial na programação,
    ele economiza tempo e código, evitando repetições manuais. Também se refere a repetições contínuas em música,
    vídeos ou narrativas (ex: loops temporais).



    LAYOUT

    O que é? Organização visual de elementos.

    Layout, ou leiaute, é a organização, arranjo ou disposição física de elementos em
    um espaço (página, tela ou ambiente), visando funcionalidade e estética. Comum no design,
    publicidade e engenharia, refere-se ao esboço, plano ou estrutura de um projeto. Sinônimos incluem:
    esquema, projeto, arranjo, design, plano, esboço e esboço.



    M

    MOBILE FIRST

    O que é? Estratégia de desenvolvimento focada em dispositivos móveis.

    Mobile First é uma estratégia de design e desenvolvimento web onde sites e aplicativos são
    planejados e criados inicialmente para dispositivos móveis (smartphones/tablets).
    O foco é priorizar a experiência do usuário em telas menores e com menos dados, adaptando posteriormente
    para desktops.



    MARGIN

    O que é? Espaço externo de um elemento no CSS.

    No contexto de desenvolvimento web (CSS), margin (margem) define o espaçamento externo ao redor de
    um elemento, situando-se fora da borda e separando-o de outros elementos vizinhos. Diferente do padding
    (interno), a margem cria "respiro" transparente ao redor do box model.



    N

    NAVEGADOR

    O que é? Programa usado para acessar sites.

    Um navegador (ou browser) é um programa ou aplicativo instalado no computador ou celular
    usado para acessar, navegar e visualizar sites na internet. Ele traduz códigos (HTML, CSS)
    em páginas web visíveis, permitindo interagir com textos, imagens e vídeos. Exemplos populares
    incluem Google Chrome, Mozilla Firefox, Microsoft Edge e Safari.



    NODE.JS

    O que é? Ambiente para executar JavaScript no servidor.

    O Node.js é um ambiente de execução (runtime) JavaScript de código aberto e multiplataforma,
    construído sobre o motor V8 do Google Chrome, que permite executar código JavaScript fora do navegador.
    Ele possibilita o desenvolvimento de aplicações Back-end (servidor) rápidas e escaláveis, utilizando uma
    arquitetura assíncrona orientada a eventos.



    O

    OBJETO

    O que é? Estrutura que armazena dados e comportamentos.

    Um objeto na programação é uma unidade autônoma que representa uma entidade (real ou abstrata),
    unindo dados (atributos) e comportamentos (métodos). Eles são instâncias de classes (moldes) e
    servem para organizar o código de forma modular, facilitar a reutilização e modelar sistemas complexos.



    P

    PYTHON

    O que é? Linguagem de programação simples e poderosa.

    Python é uma linguagem de programação de alto nível, interpretada, de propósito geral e com sintaxe clara,
    focada na legibilidade do código. É amplamente usada para automação, análise de dados, aprendizado de máquina
    e desenvolvimento web. Popular pela simplicidade, é considerada ideal para iniciantes.


    PARÂMETRO

    O que é? Valor passado para uma função.

    Parâmetro é um elemento, valor ou critério que serve como referência, norma ou limite para medir,
    avaliar ou definir um sistema. Em termos práticos, é uma medida que caracteriza uma população inteira
    na estatística (ex: média populacional) ou uma configuração/opção passada a um programa de computador
    para alterar seu funcionamento.



    R

    RESPONSIVO

    O que é? Layout que se adapta a diferentes telas.

    Responsivo é um adjetivo que indica algo que responde, reage ou se adapta rapidamente e
    de forma adequada a um estímulo, situação ou comando. Comum em tecnologia e comportamento,
    significa que algo é ajustável, reativo ou oferece uma resposta clara. Synônimos incluem reativo,
    reagente, adaptável, atento e sensível.



    S

    SERVIDOR

    O que é? Computador que fornece dados para outros.

    Um servidor é um computador ou sistema de alto desempenho, físico ou virtual, que armazena,
    processa e distribui dados, sites e aplicativos para outros dispositivos (chamados de clientes) em uma rede.
    Eles funcionam 24/7, garantindo rapidez e segurança, sendo essenciais para atividades na internet,
    como e-mails e streaming.


    STRING

    O que é? Um tipo de dado textual.

    "String" é um termo da computação que define uma sequência de caracteres (letras, números, símbolos)
    usada para representar textos. É um tipo de dado essencial para manipular palavras e frases em programação.
    No inglês, significa corda, barbante ou fio, e pode ser usada como substantivo ou verbo (amarrar).



    T

    TAG

    O que é? Elemento usado na estrutura HTML.

    Tags (etiquetas) na programação, especialmente em linguagens de marcação como HTML e XML,
    são comandos que delimitam, estruturam e dão significado ao conteúdo. Geralmente compostas por tags
    de abertura () e fechamento (), instruem navegadores a exibir elementos como parágrafos,
    imagens e links, sendo fundamentais para SEO e acessibilidade.



    U

    URL

    O que é? Endereço de um recurso na internet.

    URL significa Uniform Resource Locator (Localizador Uniforme de Recursos).
    No contexto de programação e desenvolvimento web, é o endereço único utilizado para localizar e
    acessar recursos na internet, como páginas HTML, imagens, vídeos ou APIs.



    V

    VARIÁVEL

    O que é? Espaço usado para armazenar dados.

    Uma variável na programação é um espaço nomeado na memória do computador usado para armazenar,
    recuperar e manipular dados durante a execução de um programa. Funciona como uma "caixa" rotulada
    (identificador) que guarda um valor (número, texto, etc.) que pode mudar (variar) ao longo do tempo,
    sendo fundamental para a lógica e o funcionamento de qualquer software.



    W

    WEB

    O que é? Ambiente de páginas e sistemas na internet.

    A programação web é o processo de criação de sites e aplicações funcionais acessíveis via navegadores,
    utilizando linguagens como HTML, CSS e JavaScript para estruturar, estilizar e interagir.
    Ela baseia-se na arquitetura cliente-servidor.



    X

    XML

    O que é? Linguagem de marcação para dados.

    XML (Extensible Markup Language) é uma linguagem de marcação que organiza e armazena dados de forma
    estruturada e hierárquica, utilizando tags personalizadas. Diferente de linguagens de programação,
    o XML não realiza operações, mas foca na definição e intercâmbio de informações entre sistemas variados.
    É um padrão aberto definido pela W3C, focado na flexibilidade.



    Y

    YAML

    O que é? Formato de dados usado em configurações.

    YAML (YAML Ain't Markup Language) é uma linguagem de serialização de dados focada na
    legibilidade humana, amplamente utilizada para arquivos de configuração, automação e troca de dados.
    Sua sintaxe minimalista usa indentação (espaços) para estruturar dados, tornando-a ideal
    para DevOps (ex: Docker, Kubernetes) e projetos que exigem clareza.



    Z

    Z-INDEX

    O que é? Define a ordem de camadas no CSS.

    O z-index é uma propriedade CSS que controla a ordem de empilhamento (profundidade)
    dos elementos em uma página web. Ele determina qual elemento fica "na frente" ou "atrás" de
    outro quando eles se sobrepõem.
