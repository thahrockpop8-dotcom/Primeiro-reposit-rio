A

Algoritmo

Sequência lógica de passos usada para resolver um problema.

É uma sequência lógica, finita e definida de instruções passo a passo para resolver um problema ou
realizar uma tarefa. Funcionam como "receitas" que guiam o computador, essenciais para a automoção e
criação de software. Vida real: Uma receita de bolo, o manual de montagem de um móvel,
ou o processo de trocar uma lâmpada. Computação: O algoritmo sugere em redes sociais,
o sistema que decide o que aparece no Youtube, ou um programa simples de calculadora.

API

Interface que permite a comunicação entre diferentes sistemas.

As APIs são um conjunto de padrões que fazem parte de uma interface.
As APIs permitem a criação de plataformas de maneira mais simples e prática para desenvolvedores.
A partir deles (APiS), é possível criar softwares, aplicativos, programas e plataformas diversas.
Por exemplo, apps desemvolvidos para celulares Android e Iphone (iOS) são criados a paritr de padrões definidos
e disponibilizados pelas APIs de cada sistema operacional.

Array

Estrutura de dados que armazena múltiplos valores em uma única variável.

Um array (ou arranjo/vetor) é uma estrutura de dados fundamental que armazena uma coleção ordenada de elementos,
geralmente do mesmo tipo, em posições contíguas na memória. Cada elemento é acessado por um índice numérico,
que frequentemente começa em zero. São ideais para agrupar múltiplos dados sob uma única variável,
facilitando o gerenciamento e a manipulação.

ASCII

Padrão que representa caracteres em formato numérico.

O ASCII é um código que foi proposto por Robert W. Bemer como uma solução para unificar a
representação de caracteres alfanuméricos em computadores. Antes de 1960, cada computador utilizava
uma regra diferente para representar estes caracteres e o código ASCII nasceu para se tornar comum
entre todas as máquinas.

B

Backend

Parte do sistema responsável pela lógica e processamento de dados.

O back-end é a parte "invisível" de uma aplicação (servidor, banco de dados e lógica) que processa informações,
gerencia regras de negócio e garante o funcionamento seguro do sistema.
Diferente do front-end (interface do usuário), o back-end manipula dados,
autentica usuários e conecta aplicativos a servidores.

Banco de Dados

Sistema organizado para armazenar e gerenciar informações.

Os bancos de dados armazenam informações que podem ser usadas para diferentes finalidades,
incluindo análise, exploração e consulta.
Auxiliando tanto em tomadas de decisões como no funcionamento de sistemas ou programas.
Os bancos de dados são fundamentais para a construção dessa arquitetura de dados.
Eles são mais do que apenas um lugar para armazenar informações. Em vez disso,
permitem que as organizações gerenciem dados de forma centralizada, reforcem a integridade dos dados e
os padrões de segurança e facilitem o acesso a dados.

Boolean

Tipo de dado que representa verdadeiro ou falso.

Um booleano (ou boolean) é um tipo de dado lógico na computação que representa apenas
dois estados possíveis: verdadeiro (true) ou falso (false).
Nomeado em homenagem a George Boole, esse tipo é fundamental para operações condicionais,
permitindo que algoritmos tomem decisões baseadas em lógica (AND, OR, NOT)
